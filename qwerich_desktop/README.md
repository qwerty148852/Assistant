# Qwerich Desktop Application

Qwerich - это кроссплатформенное десктоп-приложение с графическим интерфейсом, созданное для упрощения взаимодействия с системой и общения с виртуальным помощником.

## Философия проекта

Qwerich разработан с целью предоставить пользователю удобный и интуитивно понятный интерфейс для:
- Общения с виртуальным помощником
- Мониторинга состояния системы
- Обмена сообщениями в локальной сети
- Настройки персональных предпочтений

## Особенности

- Современный интерфейс в стиле Material Design
- Поддержка 5 цветовых тем
- Адаптивный дизайн
- Локализация на русском языке
- Поддержка работы в локальной сети

## Архитектура и Технологический Стек

- **GUI-фреймворк:** Kivy с набором компонентов KivyMD
- **База данных:** SQLite (встроенная в Python)
- **Сеть (для мессенджера):** Встроенная библиотека asyncio и socket
- **Сбор системной информации:** Библиотека psutil
- **Обработка естественных команд:** difflib для "нечёткого" сравнения запросов

## Установка и запуск

1. Убедитесь, что у вас установлен Python 3.10+
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите приложение:
   ```bash
   python main.py
   ```

## Модули

### 1. Модуль Регистрации и Авторизации
- Вход (Login) с полями email/логин и пароля
- Регистрация (Sign Up) с валидацией данных
- Хэширование паролей для безопасности

### 2. Чат с Qwerich
- Обработка команд с использованием "нечёткого поиска"
- Базовый набор команд: приветствие, погода, системная информация
- Сохранение истории чата в базе данных

### 3. Встроенный LAN-Мессенджер
- Обнаружение пользователей в локальной сети через UDP-широковещание
- Обмен сообщениями через TCP-соединения
- Отображение статуса "печатает..."

### 4. Сбор информации об устройстве
- Отображение информации о ЦПУ, памяти, дисках и сети
- Визуализация через прогресс-бары и карточки

### 5. Пользовательский Интерфейс и Темы
- 5 цветовых тем: Deep Forest, Ocean Blue, Dark Amethyst, Light Breeze, True Black
- Адаптивный дизайн для разных разрешений экрана

### 6. Полная документация
- Встроенный раздел справки с описанием всех функций

### 7. Настройки
- Управление внешним видом, учетной записью, конфиденциальностью и мессенджером

## Цветовые темы

1. **Deep Forest (Основная):** Темно-зеленая палитра (`#0a2f0a`, `#1a4d1a`, акцент `#2ecc71`)
2. **Ocean Blue:** Глубокий синий (`#0d1b2a`, `#1b263b`, акцент `#48cae4`)
3. **Dark Amethyst:** Темно-фиолетовая (`#1a1a2e`, `#16213e`, акцент `#9d4edd`)
4. **Light Breeze:** Светлая (`#f8f9fa`, `#e9ecef`, акцент `#0a2f0a`)
5. **True Black:** Абсолютно темная (`#000000`, `#121212`, акцент `#00ff00`)

## Запуск в headless-режиме

Для тестирования в системах без графического интерфейса можно использовать виртуальный дисплей:

```bash
export KIVY_WINDOW=egl_rpi
# или
export KIVY_GL_BACKEND=gl
```
